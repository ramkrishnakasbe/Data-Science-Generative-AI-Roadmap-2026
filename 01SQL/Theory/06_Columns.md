# Columns

## What is a Column?

A column represents an attribute of an entity.

---

## Example

Employee Table

| Employee_ID | Name | Salary |
| ----------- | ---- | ------ |

Columns:

* Employee_ID
* Name
* Salary

---

## Characteristics

* Has a name
* Has a data type
* Stores similar information

---

## Common Data Types

* INT
* VARCHAR
* DATE
* BOOLEAN
* FLOAT

---

## Interview Questions

### What is a column?

An attribute stored in a table.

### Difference between row and column?

Rows store records, columns store attributes.

---

## Key Takeaways

✔ Defines table structure

✔ Stores one type of information

✔ Uses data types
