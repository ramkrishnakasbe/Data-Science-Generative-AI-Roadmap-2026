# Database Basics

## What is Data?

Data is a collection of raw facts, figures, observations, or measurements.

Examples:

| Customer_ID | Customer_Name | City   |
| ----------- | ------------- | ------ |
| 101         | Ram           | Pune   |
| 102         | Amit          | Mumbai |

---

## What is a Database?

A database is an organized collection of data stored electronically and managed efficiently.

Think of a database as a digital warehouse that stores information in a structured manner.

Examples:

* Customer Database
* Employee Database
* Product Database
* Banking Database

---

## Why Do We Need Databases?

Without databases:

* Data gets duplicated
* Data becomes difficult to search
* Reporting becomes slow
* Data integrity issues arise

Databases help:

* Store large amounts of data
* Retrieve information quickly
* Maintain consistency
* Support business applications

---

## Types of Databases

### Relational Databases

Store data in tables.

Examples:

* PostgreSQL
* MySQL
* SQL Server
* Oracle

### Non-Relational Databases

Store data in documents, key-value pairs, or graphs.

Examples:

* MongoDB
* Cassandra
* Redis
* Neo4j
