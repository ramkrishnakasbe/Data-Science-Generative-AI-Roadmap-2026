# DBMS vs RDBMS

## What is DBMS?

Database Management System used to store and manage data.

Examples:

* File Systems
* Older DBMS Systems

---

## What is RDBMS?

Relational Database Management System.

Stores data in related tables.

Examples:

* PostgreSQL
* MySQL
* SQL Server

---

## Comparison

| Feature        | DBMS    | RDBMS     |
| -------------- | ------- | --------- |
| Storage        | Files   | Tables    |
| Relationships  | Limited | Supported |
| Normalization  | Limited | Supported |
| Data Integrity | Low     | High      |
| Scalability    | Low     | High      |

---

## Interview Questions

### Difference between DBMS and RDBMS?

RDBMS stores data in related tables and supports relationships.

### Which is better?

RDBMS for enterprise applications.

---

## Key Takeaways

✔ RDBMS is an advanced form of DBMS

✔ Supports relationships

✔ Better integrity and scalability
