# Rows

## What is a Row?

A row represents a single record in a table.

Also called:

* Record
* Tuple

---

## Example

| Employee_ID | Name |
| ----------- | ---- |
| 1           | Ram  |
| 2           | Amit |

Each entry is a row.

---

## Real World Example

Customer Table

Each customer represents one row.

---

## Interview Questions

### What is a row?

A single record in a table.

### Another name for row?

Tuple or record.

---

## Key Takeaways

✔ Represents one record

✔ Stored within tables
