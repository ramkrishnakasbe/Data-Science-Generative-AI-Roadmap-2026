# RDBMS (Relational Database Management System)

## What is RDBMS?

RDBMS is software used to create, manage, and maintain relational databases.

Data is stored in the form of tables.

---

## Popular RDBMS Systems

* PostgreSQL
* MySQL
* Microsoft SQL Server
* Oracle Database

---

## Characteristics of RDBMS

### Tables

Data is stored in rows and columns.

### Relationships

Tables can be connected using keys.

### Constraints

Rules ensure data quality.

### SQL Support

Uses SQL for data manipulation.

---

## Example

Customers Table

| Customer_ID | Name |
| ----------- | ---- |
| 1           | Ram  |

Orders Table

| Order_ID | Customer_ID |
| -------- | ----------- |
| 101      | 1           |

Relationship:

Customer_ID connects both tables.
