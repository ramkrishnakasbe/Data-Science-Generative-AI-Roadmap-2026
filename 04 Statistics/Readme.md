# Statistics

## Overview

Statistics is the science of collecting, analyzing, interpreting, and drawing conclusions from data. It provides the mathematical foundation for Data Science, Machine Learning, Experimentation, and Predictive Analytics.

> Note: Descriptive Statistics is covered separately under Exploratory Data Analysis (EDA).

---

## Why Statistics for Data Science?

* Understand uncertainty in data
* Make predictions from samples
* Validate assumptions
* Measure relationships between variables
* Build and evaluate machine learning models
* Support data-driven decision making
