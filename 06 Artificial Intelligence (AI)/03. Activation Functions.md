# 3. Activation Functions

## 1. What is an Activation Function?

An **activation function** determines the output of a neuron after the weighted sum and bias are calculated.

Basic neuron:

```text
Input
  ↓
Weighted Sum
  ↓
Add Bias
  ↓
Activation Function
  ↓
Output
```

Mathematically:

```text
z = Wx + b
```

Then:

```text
a = f(z)
```

Where:

* `z` = pre-activation / weighted sum
* `f` = activation function
* `a` = activation/output

---

# 2. Why Do We Need Activation Functions?

The primary purpose of activation functions is to introduce **non-linearity** into neural networks.

Without activation functions:

```text
Input
 ↓
Linear Layer
 ↓
Linear Layer
 ↓
Linear Layer
 ↓
Output
```

Multiple linear transformations can be combined into a single linear transformation.

Therefore, the network cannot effectively learn complex nonlinear relationships.

With activation functions:

```text
Input
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
ReLU
 ↓
Output
```

The network can learn complex nonlinear functions.

---

```text
Activation Functions
```

# 4. Step Function

The step function produces a discrete output.

```text
f(z) = 1  if z ≥ 0
f(z) = 0  if z < 0
```

Example:

```text
z = 5  → 1
z = -2 → 0
```

### Limitation

The step function is not suitable for gradient-based learning because its derivative is zero or undefined at the threshold.

Therefore, modern neural networks generally use differentiable activation functions instead.

---

# 5. Sigmoid Function

The sigmoid function converts values into the range:

```text
0 to 1
```

Formula:

```text
σ(z) = 1 / (1 + e^(-z))
```

Examples:

```text
σ(0) ≈ 0.5
```

```text
σ(large positive value) → 1
```

```text
σ(large negative value) → 0
```

---

# 6. Sigmoid Graph Behavior

Conceptually:

```text
Output
  1 |                 ______
    |              __/
    |           __/
 0.5|---------/
    |       /
    |    __/
  0 |___/
    +----------------------→ z
```

Sigmoid has an S-shaped curve.

---

# 7. Sigmoid Advantages

Advantages:

* Output is bounded between 0 and 1
* Easy to interpret as probability
* Smooth and differentiable
* Useful for binary classification output

Common use:

```text
Binary Classification
```

Example:

```text
P(customer will churn) = 0.82
```

---

# 8. Sigmoid Disadvantages

### 1. Vanishing Gradient

For very large positive or negative values, the gradient becomes very small.

```text
Large |z|
   ↓
Small Gradient
   ↓
Small Updates
```

### 2. Not Zero-Centered

Output range:

```text
0 to 1
```

This can make optimization less convenient compared with zero-centered activations such as tanh.

### 3. Saturation

For extreme values, sigmoid becomes nearly flat.

---

# 9. Sigmoid Derivative

The derivative is:

```text
σ'(z) = σ(z)(1 - σ(z))
```

The maximum derivative is:

```text
1/4
```

Therefore, repeated multiplication of sigmoid derivatives through many layers can cause gradients to become very small.

---

# 10. Tanh Function

Tanh maps values to:

```text
-1 to 1
```

Formula:

```text
tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))
```

---

# 11. Tanh Behavior

```text
Output
  1 |              ______
    |           __/
    |        __/
  0 |-------/
    |     __
    |   _/
 -1 |___/
    +----------------------→ z
```

It is centered around zero.

---

# 12. Tanh Advantages

* Zero-centered
* Stronger output range than sigmoid
* Useful for hidden representations in some architectures
* Historically common in RNNs

---

# 13. Tanh Disadvantages

Like sigmoid:

* Can suffer from vanishing gradients
* Saturates for large positive/negative inputs
* Generally not the default hidden-layer activation in modern deep networks

---

# 14. Sigmoid vs Tanh

| Feature                  | Sigmoid     | Tanh        |
| ------------------------ | ----------- | ----------- |
| Range                    | 0 to 1      | -1 to 1     |
| Zero-centered            | No          | Yes         |
| Vanishing Gradient       | Yes         | Yes         |
| Common Hidden Activation | Less common | Less common |
| Binary Output            | Common      | Rare        |
| Historical RNN Use       | Yes         | Yes         |

---

# 15. ReLU

ReLU stands for:

**Rectified Linear Unit**

Formula:

```text
ReLU(z) = max(0, z)
```

Therefore:

```text
z < 0 → 0
z ≥ 0 → z
```

Examples:

```text
ReLU(-5) = 0
```

```text
ReLU(0) = 0
```

```text
ReLU(7) = 7
```

---

# 16. ReLU Graph

```text
Output
  |
  |          /
  |        /
  |      /
  |    /
  |___/____________→ z
      0
```

Negative values are mapped to zero.

Positive values pass through unchanged.

---

# 17. Why ReLU Became Popular

ReLU has several advantages:

* Simple
* Computationally efficient
* Does not saturate for positive values
* Often improves optimization compared with sigmoid/tanh in deep networks
* Produces sparse activations because negative inputs become zero

---

# 18. ReLU Derivative

For positive values:

```text
ReLU'(z) = 1
```

For negative values:

```text
ReLU'(z) = 0
```

At `z = 0`, the function is not differentiable in the classical sense; implementations use a defined convention/subgradient.

---

# 19. Dying ReLU Problem

A neuron can become inactive if it consistently receives negative inputs.

```text
Negative Input
      ↓
ReLU
      ↓
0
      ↓
Gradient = 0
      ↓
Neuron may stop learning
```

This is called the:

**Dying ReLU Problem**

---

# 20. Leaky ReLU

Leaky ReLU addresses the zero-gradient problem for negative inputs.

Formula:

```text
LeakyReLU(z) = z       if z > 0
LeakyReLU(z) = αz      if z ≤ 0
```

Where `α` is a small positive value.

Example:

```text
α = 0.01
```

Then:

```text
LeakyReLU(-5) = -0.05
```

Instead of:

```text
ReLU(-5) = 0
```

---

# 21. ReLU vs Leaky ReLU

| Feature           | ReLU        | Leaky ReLU      |
| ----------------- | ----------- | --------------- |
| Positive Input    | z           | z               |
| Negative Input    | 0           | αz              |
| Negative Gradient | 0           | Small           |
| Dying ReLU        | Possible    | Reduced         |
| Complexity        | Very simple | Slightly higher |

---

# 22. PReLU

PReLU stands for:

**Parametric ReLU**

Formula:

```text
PReLU(z) = z       if z > 0
PReLU(z) = αz      if z ≤ 0
```

Difference:

```text
Leaky ReLU → α is usually fixed
PReLU      → α is learned
```

Therefore, `α` becomes a trainable parameter.

---

# 23. ELU

ELU stands for:

**Exponential Linear Unit**

Formula:

```text
ELU(z) = z                  if z > 0
ELU(z) = α(e^z - 1)         if z ≤ 0
```

ELU provides a smooth negative region and can produce negative outputs.

---

# 24. ELU Advantages

Potential benefits:

* Avoids hard zero output for all negative values
* Negative outputs can help keep activations closer to zero
* Smooth negative region

Disadvantage:

```text
More computationally expensive than ReLU
```

because it uses an exponential function.

---

# 25. SELU

SELU stands for:

**Scaled Exponential Linear Unit**

SELU is designed to encourage **self-normalizing neural networks** under specific architectural and initialization assumptions.

SELU is related to:

* ELU
* Specific weight initialization
* Appropriate network architecture
* Proper input normalization

SELU is commonly discussed with:

```text
Self-Normalizing Neural Networks
```

---

# 26. GELU

GELU stands for:

**Gaussian Error Linear Unit**

A commonly used formulation is:

```text
GELU(x) = xΦ(x)
```

Where `Φ(x)` is the standard normal cumulative distribution function.

An approximation is:

```text
GELU(x) ≈ 0.5x[1 + tanh(√(2/π)(x + 0.044715x³))]
```

GELU is widely used in:

* Transformers
* BERT
* Vision Transformers
* Modern deep learning architectures

---

# 27. Why GELU is Important

GELU provides a smooth nonlinear transformation.

Unlike ReLU:

```text
ReLU → hard threshold
GELU → smooth gating-like behavior
```

GELU is particularly important for Transformer-based models.

---

# 28. Swish

Swish is defined as:

```text
Swish(x) = x × sigmoid(x)
```

or:

```text
Swish(x) = x / (1 + e^(-x))
```

Swish is smooth and non-monotonic.

It has been used in several modern deep learning architectures.

---

# 29. Mish

Mish is defined as:

```text
Mish(x) = x × tanh(softplus(x))
```

where:

```text
softplus(x) = ln(1 + e^x)
```

Mish is:

* Smooth
* Non-monotonic
* Computationally more expensive than ReLU

---

# 30. Softmax

Softmax converts a vector of logits into a probability distribution.

Formula:

```text
P(y=i) = e^(zᵢ) / Σⱼ e^(zⱼ)
```

Properties:

```text
0 ≤ P(y=i) ≤ 1
```

and:

```text
Σᵢ P(y=i) = 1
```

---

# 31. Softmax Example

Suppose model outputs logits:

```text
[2.0, 1.0, 0.1]
```

Softmax converts them approximately into:

```text
Class A → 0.66
Class B → 0.24
Class C → 0.10
```

The probabilities sum to approximately:

```text
1.00
```

The predicted class is:

```text
Class A
```

because it has the highest probability.

---

# 32. Why Softmax Is Used

Softmax is commonly used in the output layer for:

```text
Multi-Class Classification
```

Example:

```text
Cat
Dog
Horse
```

Output:

```text
Cat   = 0.70
Dog   = 0.20
Horse = 0.10
```

---

# 33. Softmax vs Sigmoid

| Feature          | Sigmoid                   | Softmax                    |
| ---------------- | ------------------------- | -------------------------- |
| Output           | Independent probabilities | Probability distribution   |
| Classes          | Binary / Multi-label      | Multi-class                |
| Outputs Sum to 1 | No                        | Yes                        |
| Typical Use      | Binary classification     | Multi-class classification |

### Important

For multi-label classification:

```text
Image → Cat + Dog
```

Sigmoid is generally used because multiple classes can be true simultaneously.

For mutually exclusive classes:

```text
Image → Cat OR Dog OR Horse
```

Softmax is generally appropriate.

# 35. Linear Activation

Linear activation:

```text
f(x) = x
```

There is no nonlinear transformation.

Commonly used for:

```text

```

Example:

```text
House Price = 8,500,000
```

A regression output does not need to be restricted to `[0, 1]`.

# 41. Activation Function Comparison

| Function   | Range                    | Main Advantage               | Main Problem            |
| ---------- | ------------------------ | ---------------------------- | ----------------------- |
| Step       | 0 / 1                    | Simple                       | Not gradient-friendly   |
| Sigmoid    | 0 to 1                   | Probability                  | Vanishing gradient      |
| Tanh       | -1 to 1                  | Zero-centered                | Vanishing gradient      |
| ReLU       | 0 to ∞                   | Simple, efficient            | Dying ReLU              |
| Leaky ReLU | -∞ to ∞                  | Reduces dying ReLU           | Extra hyperparameter    |
| PReLU      | -∞ to ∞                  | Learnable negative slope     | More parameters         |
| ELU        | -α to ∞                  | Smooth negative region       | More computation        |
| GELU       | Approximately -0.17 to ∞ | Smooth, Transformer-friendly | More computation        |
| Swish      | Approximately -0.28 to ∞ | Smooth, non-monotonic        | More computation        |
| Softmax    | 0 to 1                   | Class probabilities          | Mainly output-layer use |

# 42. Saturation

An activation function is said to saturate when its output changes very little despite large changes in input.

Sigmoid:

```text
Large Positive Input
       ↓
Output ≈ 1
       ↓
Gradient ≈ 0
```

Large negative input:

```text
Large Negative Input
       ↓
Output ≈ 0
       ↓
Gradient ≈ 0
```

This contributes to vanishing gradients.

---

# 43. Vanishing Gradient

During backpropagation:

```text
Gradient
   ↓
× Small Derivative
   ↓
Smaller Gradient
   ↓
× Small Derivative
   ↓
Very Small Gradient
```

This is one reason ReLU-family and other modern activations became important in deep networks.

---

# 44. Exploding Gradient

The opposite problem:

```text
Gradient
   ↓
× Large Derivative
   ↓
Larger Gradient
   ↓
× Large Derivative
   ↓
Huge Gradient
```

Possible consequences:

* Unstable training
* Very large parameter updates
* NaN values
* Training failure

---

# 45. Activation Function and Gradient Flow

Good activation selection can help gradient flow.

```text
Poor Gradient Flow
       ↓
Slow / Unstable Learning
```

A suitable activation:

```text
Better Gradient Flow
       ↓
More Stable Optimization
```

However, activation function alone does not solve all optimization problems.

Other factors include:

* Initialization
* Architecture
* Learning rate
* Normalization
* Optimizer
* Residual connections


Typical:

Purpose:

```text

```

```text

```

# 47. Common Mistakes

### Mistake 1

Using sigmoid in every hidden layer.

Problem:

```text
Vanishing Gradients
```

---

### Mistake 2

Using softmax for multi-label classification.

If multiple classes can simultaneously be true:

```text
Cat = 1
Dog = 1
```

softmax is generally inappropriate because its outputs compete and sum to 1.

---

### Mistake 3

Using sigmoid for unrestricted regression.

Sigmoid restricts:

```text
Output ∈ [0, 1]
```

For ordinary unrestricted regression, a linear output is usually more appropriate.

---

### Mistake 4

Assuming ReLU has no problems.

ReLU can suffer from:

```text
Dying ReLU
```

---

### Mistake 5

Thinking activation functions alone determine model performance.

Performance depends on:

```text
Data
Architecture
Loss
Optimizer
Learning Rate
Initialization
Regularization
Training Strategy
```

---

# 48. How to Choose an Activation Function

Use this decision process:

```text
Is this the Output Layer?
        │
       Yes
        ↓
What is the task?
        │
 ┌──────┼──────────────┐
 ↓      ↓              ↓
Binary  Multi-Class    Regression
 ↓      ↓              ↓
Sigmoid Softmax        Linear
```

For hidden layers:

```text
Hidden Layer
     ↓
Start with a suitable modern default
     ↓
ReLU / GELU / architecture-specific activation
     ↓
Tune based on validation performance
```

# 49. Interview Scenario

### Question

You are building a binary classification neural network. Which activation functions would you choose?

### Answer

A common design is:

```text
Hidden Layers
     ↓
ReLU / GELU
     ↓
Output Layer
     ↓
Sigmoid
```

The hidden activation provides nonlinear representation learning, while sigmoid converts the final output into a value between 0 and 1.

---

# 50. Interview Scenario

### Question

Why not use ReLU in the output layer for binary classification?

ReLU outputs:

```text
0 to ∞
```

It does not naturally represent a probability between 0 and 1.

Sigmoid provides:

```text
0 to 1
```

and is therefore commonly used for binary classification probability output.

---

# 51. Interview Scenario

### Question

Why is ReLU preferred over sigmoid in many hidden layers?

Key points:

```text
ReLU
├── Simple computation
├── Nonlinear
├── Positive region has constant gradient
├── Often improves optimization in deep networks
└── Computationally efficient
```

Sigmoid can saturate and produce very small gradients.

---

# 52. Interview Scenario

### Question

What is the dying ReLU problem?

A ReLU neuron can output zero for negative inputs.

If a neuron consistently receives negative values:

```text
ReLU(z) = 0
```

and:

```text
ReLU'(z) = 0
```

The neuron may stop receiving useful gradient updates.

This is called the **dying ReLU problem**.

Possible alternatives:

```text
Leaky ReLU
PReLU
ELU
```

---

# 53. Interview Scenario

### Question

Why is GELU popular in Transformers?

GELU provides a smooth nonlinear transformation and has been adopted in important Transformer architectures such as BERT.

It is not simply a universal replacement for ReLU; activation choice depends on architecture and model design.
