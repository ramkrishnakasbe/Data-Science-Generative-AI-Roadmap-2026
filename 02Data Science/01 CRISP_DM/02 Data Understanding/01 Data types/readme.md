# Data Types

## Overview

Understanding data types is fundamental in Data Science, Machine Learning, Analytics, and AI.

Different types of data require different storage methods, preprocessing techniques, visualization approaches, and machine learning algorithms.

---

## Learning Objectives

After completing this section, you will be able to:

- Differentiate between continuous and discrete data
- Understand qualitative and quantitative data
- Identify structured, semi-structured, and unstructured data
- Understand Big Data concepts
- Differentiate time-based datasets
- Recognize balanced and imbalanced datasets
- Understand batch and streaming data systems
