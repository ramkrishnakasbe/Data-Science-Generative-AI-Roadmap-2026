# Structured vs Semi-Structured vs Unstructured Data

# Data Classification

```text
Data
│
├── Structured
├── Semi-Structured
└── Unstructured
```

---

# 1. Structured Data

## Definition

Data stored in rows and columns with predefined schema.

### Examples

- SQL Tables
- Excel
- CSV

---

# 2. Semi-Structured Data

## Definition

Data with flexible structure but containing tags or keys.

### Examples

- JSON
- XML
- HTML

---

# 3. Unstructured Data

## Definition

Data without predefined schema.

### Examples

- Images
- Videos
- Audio
- PDFs
- Emails

---

# Comparison Table

| Feature | Structured | Semi-Structured | Unstructured |
|----------|------------|----------------|-------------|
| Schema | Fixed | Flexible | None |
| Example | SQL | JSON | Image |
| Querying | Easy | Moderate | Difficult |

---

# Interview Questions

### Q1. What is Structured Data?

Data organized into rows and columns.

### Q2. Is JSON Structured Data?

No, Semi-Structured.

### Q3. Give examples of Unstructured Data.

Images, Videos, Audio.

### Q4. Why is Unstructured Data difficult?

No predefined schema.

### Q5. Which type dominates Big Data?

Unstructured Data.
