# Qualitative vs Quantitative Data

# Data Classification

```text
Data
│
├── Quantitative Data
│
└── Qualitative Data
```

---

# 1. Quantitative Data

## Definition

Quantitative data represents numerical values that can be measured or counted.

### Examples

- Salary
- Age
- Weight
- Height
- Revenue

### Characteristics

- Numerical
- Supports mathematical operations
- Used in statistical analysis

---

# 2. Qualitative Data

## Definition

Qualitative data represents labels, categories, or attributes.

### Examples

- Gender
- Country
- Blood Group
- Department

### Characteristics

- Non-numerical
- Descriptive
- Used for classification

---

# Comparison

| Feature | Quantitative | Qualitative |
|----------|-------------|-------------|
| Nature | Numerical | Categorical |
| Example | Salary | Country |
| Analysis | Mathematical | Classification |

# Interview Questions

### Q1. Difference between Qualitative and Quantitative Data?

Quantitative data contains numerical values while qualitative data contains categories or labels.

### Q2. Is Gender Qualitative or Quantitative?

Qualitative.

### Q3. Is Salary Qualitative or Quantitative?

Quantitative.

### Q4. Which data type is used for Machine Learning?

Both are commonly used.

### Q5. Is Customer Satisfaction Qualitative?

Usually Ordinal Qualitative Data.
