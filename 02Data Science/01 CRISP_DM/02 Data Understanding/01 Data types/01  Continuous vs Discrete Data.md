# 1. Numerical Data

Numerical data consists of values that can be measured or counted.

Examples:

- Age
- Salary
- Height
- Number of Orders

---

# 1.1 Continuous Data

## Definition

Continuous data can take any value within a range.

### Examples

- Height
- Weight
- Temperature
- Income

---

# 1.1.1 Interval Scale

## Definition

Values have equal intervals but no true zero.

### Examples

- Temperature (°C)
- Temperature (°F)
- IQ Score

### Characteristics

- Equal intervals
- No absolute zero
- Ratios are meaningless

---

# 1.1.2 Ratio Scale

## Definition

Values have equal intervals and a true zero.

### Examples

- Height
- Weight
- Salary
- Distance
- Age

### Characteristics

- True zero exists
- Ratios are meaningful

### Interview Point

Ratio scale is the most preferred scale because all mathematical operations are valid.

---

# 1.2 Discrete Data

## Definition

Discrete data contains countable values.

### Examples

- Number of Students
- Number of Cars
- Number of Employees

---

# 1.2.1 Count Data

Count data is obtained through counting events or objects.

### Examples

- Orders per Day
- Website Visits
- Customer Count

---

# 2. Categorical Data

Categorical data represents labels or categories.

Examples:

- Gender
- Department
- Country

---

# 2.1 Binary Data

## Definition

Only two categories exist.

### Examples

- Yes / No
- Pass / Fail
- Fraud / Non-Fraud

---

# 2.2 Multiple Categories

More than two categories exist.

---

# 2.2.1 Nominal Data

## Definition

Categories without order.

### Examples

- Country
- Color
- Blood Group

---

# 2.2.2 Ordinal Data

## Definition

Categories with meaningful order.

### Examples

- Low, Medium, High
- Poor, Average, Excellent
- 1 Star to 5 Star Ratings

---
