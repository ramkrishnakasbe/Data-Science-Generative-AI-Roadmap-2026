# Graphical Representation

## What is Graphical Representation?

Graphical Representation is the process of visualizing data using charts and plots to understand:

- Distribution
- Trends
- Relationships
- Patterns
- Outliers

Visualization is a key part of Exploratory Data Analysis (EDA).

# 1. Univariate Analysis

## Definition

Analysis of a single variable.

## Objective

Understand:

- Distribution
- Central Tendency
- Spread
- Outliers

## Common Graphs

### Numerical Data

- Histogram
- Density Plot (KDE)
- Box Plot
- Violin Plot

### Categorical Data

- Bar Chart
- Pie Chart

## Example

```text
Salary Distribution
```

---

# 2. Bivariate Analysis

## Definition

Analysis of two variables together.

## Objective

Understand:

- Relationship
- Correlation
- Trends
- Comparisons

## Common Graphs

### Numerical vs Numerical

- Scatter Plot
- Line Plot

### Categorical vs Numerical

- Box Plot
- Grouped Bar Chart

### Categorical vs Categorical

- Stacked Bar Chart

## Example

```text
Experience vs Salary
```

---

# 3. Multivariate Analysis

## Definition

Analysis involving three or more variables.

## Objective

Understand:

- Complex Relationships
- Feature Interactions
- Hidden Patterns

## Common Graphs

- Pair Plot
- Heatmap
- Bubble Plot
- 3D Scatter Plot
- Parallel Coordinates Plot
- Cluster Visualization

## Example

```text
Experience vs Salary vs Education
```

---

# Key Takeaways

- Univariate Analysis studies one variable.
- Bivariate Analysis studies two variables.
- Multivariate Analysis studies three or more variables.
- Histogram and Box Plot are common univariate graphs.
- Scatter Plot is the most common bivariate graph.
- Heatmap and Pair Plot are widely used for multivariate analysis.
- Graphical Representation is a core part of EDA.
