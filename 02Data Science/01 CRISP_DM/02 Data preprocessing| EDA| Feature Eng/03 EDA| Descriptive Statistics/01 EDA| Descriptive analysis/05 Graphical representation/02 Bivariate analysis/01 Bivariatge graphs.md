# Bivariate Graphs and Plots

## Overview

Bivariate Analysis studies the relationship between two variables. It helps identify associations, trends, differences, and correlations between variables.

---

# Numerical vs Numerical

## 1. Scatter Plot

### Definition

A Scatter Plot displays the relationship between two numerical variables using points.

### Purpose

* Identify correlation
* Detect trends
* Find outliers
* Understand variable relationships

### Example Use Case

Analyzing relationship between Advertising Spend and Sales.

### Example Image

```md
![Scatter Plot](images/scatter_plot.png)
```

---

## 2. Line Plot

### Definition

A Line Plot connects data points using lines to show trends between variables.

### Purpose

* Visualize trends
* Track changes over time
* Compare observations

### Example Use Case

Monthly Sales vs Time.

```md
![Line Plot](images/line_plot.png)
```

## Numerical vs Categorical

## 3. Box Plot

### Definition

Shows the distribution of a numerical variable across categories.

### Purpose

* Compare distributions
* Detect outliers
* Compare medians

### Example Use Case

Salary distribution across Departments.

### Example Image

```md
![Box Plot](images/bivariate_boxplot.png)
```

---

## 4. Violin Plot

### Definition

Displays the distribution of a numerical variable for different categories.

### Purpose

* Compare distributions
* Understand density and spread

### Example Use Case

Exam scores across student groups.

### Example Image

```md
![Violin Plot](images/bivariate_violin_plot.png)
```

---

## 5. Bar Chart

### Definition

Represents aggregated numerical values across categories.

### Purpose

* Compare category performance
* Visualize averages or totals

### Example Use Case

Average sales by region.

```md
![Bar Chart](images/bivariate_bar_chart.png)
```

# Categorical vs Categorical

## 6. Grouped Bar Chart

### Definition

Compares frequencies across multiple categories.

### Purpose

* Compare category combinations
* Identify patterns

### Example Use Case

Gender distribution across departments.

### Example Image

```md
![Grouped Bar Chart](images/grouped_bar_chart.png)
```

---

## 7. Stacked Bar Chart

### Definition

Displays category composition within another category.

### Purpose

* Compare totals and proportions
* Understand category breakdown

### Example Use Case

Product category sales by region.

### Example Image

```md
![Stacked Bar Chart](images/stacked_bar_chart.png)
```

---

## 8. Heatmap

### Definition

Represents relationships using color intensity.

### Purpose

* Identify strong and weak relationships
* Visualize contingency tables

### Example Use Case

Correlation between categorical variables.

# Choosing the Right Plot

| Variable Types             | Recommended Plots                             |
| -------------------------- | --------------------------------------------- |
| Numerical vs Numerical     | Scatter Plot, Line Plot                       |
| Numerical vs Categorical   | Box Plot, Violin Plot, Bar Chart              |
| Categorical vs Categorical | Grouped Bar Chart, Stacked Bar Chart, Heatmap |

---

# Summary

Bivariate Analysis helps understand the relationship between two variables and provides insights useful for feature selection, business analysis, and predictive modeling.
