# 01. Type Casting and Type Conversion

# Overview

Type Casting (or Type Conversion) is the process of converting a variable or column from one data type to another. It is one of the first and most important steps in data preprocessing because real-world datasets often contain incorrect or inconsistent data types.

For example:

* Age stored as `"25"` (String) instead of `25` (Integer)
* Date stored as `"2024-01-15"` (String) instead of `Datetime`
* Salary stored as `"50000"` (Object) instead of `Float`

Converting these values into their appropriate data types ensures accurate analysis, efficient memory usage, and compatibility with machine learning algorithms.

---

# Why is Type Casting Required?

Real-world data comes from multiple sources such as:

* Excel files
* CSV files
* Databases
* APIs
* Web Scraping

During data import, columns may not always be assigned the correct data type.

Incorrect data types can lead to:

* Incorrect calculations
* Higher memory consumption
* Poor model performance
* Errors during visualization
* Errors while training machine learning models

Therefore, verifying and converting data types is one of the first preprocessing tasks.

---

# What is a Data Type?

A data type defines the kind of values a variable or column can store.

Examples:

| Data Type        | Description                    | Example      |
| ---------------- | ------------------------------ | ------------ |
| Integer (`int`)  | Whole numbers                  | 10, -5, 250  |
| Float (`float`)  | Decimal numbers                | 15.5, 99.99  |
| String (`str`)   | Text values                    | "Python"     |
| Boolean (`bool`) | True or False                  | True         |
| Datetime         | Date and Time                  | 2025-01-01   |
| Category         | Limited set of repeated values | Male, Female |

---

# Type Casting vs Type Conversion

Although both terms are often used interchangeably, there is a slight difference.

| Type Casting                                  | Type Conversion                                        |
| --------------------------------------------- | ------------------------------------------------------ |
| Manual conversion performed by the programmer | Automatic or manual conversion performed by the system |
| Explicit                                      | Implicit or Explicit                                   |
| Requires user intervention                    | May happen automatically                               |

---

# Types of Type Conversion

## 1. Implicit Type Conversion

Implicit conversion is performed automatically by Python when there is no risk of losing information.

### Example

```python
a = 10
b = 2.5

result = a + b

print(result)
print(type(result))
```

Output

```text
12.5
<class 'float'>
```

Python automatically converts the integer into a float before performing the addition.

---

## 2. Explicit Type Conversion (Type Casting)

Explicit conversion is performed manually using built-in functions.

Example:

```python
salary = "50000"

salary = int(salary)

print(salary)
print(type(salary))
```

Output

```text
50000
<class 'int'>
```

# Type Casting in NumPy

NumPy arrays have a single data type for all elements.

## Checking Data Type

```python
import numpy as np

arr = np.array([1,2,3])

print(arr.dtype)
```

Output

```text
int64
```

---

## Changing Data Type

```python
arr = arr.astype(float)

print(arr)
print(arr.dtype)
```

Output

```text
[1. 2. 3.]

float64
```

---

## String to Integer

```python
arr = np.array(["1","2","3"])

arr = arr.astype(int)
```

Output

```text
array([1,2,3])
```

---

# Type Casting in Pandas

Type conversion is frequently performed using Pandas while cleaning datasets.

## Checking Data Types

```python
import pandas as pd

df = pd.read_csv("employees.csv")

print(df.dtypes)
```

---

## Using astype()

```python
df["Age"] = df["Age"].astype(int)
```

---

## Convert Salary to Float

```python
df["Salary"] = df["Salary"].astype(float)
```

---

## Convert Column to String

```python
df["EmployeeID"] = df["EmployeeID"].astype(str)
```

---

## Convert Object to Category

```python
df["Department"] = df["Department"].astype("category")
```

Advantages:

* Reduces memory usage
* Improves performance
* Suitable for columns with repeated values

---

## Convert String to Datetime

Before

```text
01-01-2025
```

Conversion

```python
df["Joining_Date"] = pd.to_datetime(df["Joining_Date"])
```

Output

```text
2025-01-01
```

---

## Convert Multiple Columns

```python
df = df.astype({
    "Age":"int",
    "Salary":"float",
    "Gender":"category"
})
```

---

# Type Conversion Using convert_dtypes()

Pandas can automatically infer better data types.

```python
df = df.convert_dtypes()
```

Useful for large datasets where manual conversion is tedious.

---

# Handling Invalid Type Conversion

Sometimes a column contains invalid values.

Example

```text
Age

20
25
Thirty
40
```

Converting directly to integer causes an error.

```python
df["Age"].astype(int)
```

Error

```text
ValueError
```

---

## Using pd.to_numeric()

```python
df["Age"] = pd.to_numeric(
    df["Age"],
    errors="coerce"
)
```

Output

```text
20
25
NaN
40
```

Invalid values become `NaN` and can later be handled through imputation or removal.

---

# Datetime Conversion

Dates are usually imported as strings.

Example

```text
2025-01-15
```

Convert to datetime

```python
df["Date"] = pd.to_datetime(df["Date"])
```

Useful for extracting:

* Year
* Month
* Day
* Weekday
* Quarter

Example

```python
df["Year"] = df["Date"].dt.year
df["Month"] = df["Date"].dt.month
df["Day"] = df["Date"].dt.day
```

---

# Category Data Type

Columns with a limited number of repeated values should be converted to the `category` data type.

Example

```text
Gender

Male
Female
Male
Female
```

Conversion

```python
df["Gender"] = df["Gender"].astype("category")
```

Benefits:

* Lower memory usage
* Faster grouping and sorting
* Better performance

---

# Memory Optimization

Large datasets consume significant memory.

Example

```python
print(df.memory_usage(deep=True))
```

Convert repeated text columns to category.

```python
df["City"] = df["City"].astype("category")
```

Memory usage can reduce significantly for columns with many repeated values.

---

# Common Conversion Errors

| Problem       | Cause                       | Solution                             |
| ------------- | --------------------------- | ------------------------------------ |
| ValueError    | Invalid string              | Use `pd.to_numeric(errors="coerce")` |
| TypeError     | Unsupported conversion      | Verify source data type              |
| OverflowError | Value exceeds integer limit | Use larger numeric type              |

# Real-World Example

Suppose a customer dataset contains:

| CustomerID | Age  | Salary  | Joining_Date | Gender |
| ---------- | ---- | ------- | ------------ | ------ |
| C101       | "25" | "45000" | "01-01-2025" | Male   |
| C102       | "30" | "55000" | "05-02-2025" | Female |

After preprocessing:

| CustomerID | Age | Salary  | Joining_Date | Gender   |
| ---------- | --- | ------- | ------------ | -------- |
| C101       | 25  | 45000.0 | 2025-01-01   | Category |
| C102       | 30  | 55000.0 | 2025-02-05   | Category |

Now the dataset is ready for analysis and machine learning.

---

# Advantages

* Improves data consistency
* Enables mathematical operations
* Reduces memory usage
* Improves computational efficiency
* Required for many machine learning algorithms
* Simplifies feature engineering
* Improves visualization accuracy

---

# Disadvantages

* Incorrect conversion may lead to data loss
* Invalid values can generate conversion errors
* Converting floats to integers removes decimal precision
* Large-scale conversions may increase preprocessing time

---

# Summary

Type Casting is one of the first steps in data preprocessing. It ensures that every feature has the correct data type before analysis or model building. Proper type conversion improves data quality, reduces memory usage, enables accurate computations, and prevents errors during Exploratory Data Analysis (EDA) and Machine Learning. Common tools include Python's built-in conversion functions, NumPy's `astype()`, and Pandas methods such as `astype()`, `to_numeric()`, `to_datetime()`, and `convert_dtypes()`.
