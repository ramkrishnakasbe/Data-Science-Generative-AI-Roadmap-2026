# 06. Discretization / Binning / Grouping

# Overview

Discretization (also called Binning or Grouping) is the process of converting continuous numerical data into discrete categories (bins).

It is used to simplify data, reduce noise, and improve model performance for certain algorithms.

---

# Why Discretization is Used?

Discretization helps to:

- Reduce complexity of continuous variables
- Handle noisy data
- Improve interpretability
- Improve performance of some ML models
- Convert numerical features into categorical form

---

# Types of Discretization

## 6.1 Binarisation

### Definition

Binarisation converts numerical values into only **two categories (0 and 1)** based on a threshold.

---

### Example

| Age | Binary |
|-----|--------|
| 18  | 0 |
| 25  | 1 |
| 40  | 1 |

(Threshold = 20)
