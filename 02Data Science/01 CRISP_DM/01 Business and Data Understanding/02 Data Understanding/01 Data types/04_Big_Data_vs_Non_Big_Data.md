# Big Data vs Non-Big Data

# Data Classification

```text
Data
│
├── Traditional Data
└── Big Data
```

---

# 1. Traditional Data

## Definition

Data manageable using traditional databases.

### Examples

- Excel Files
- SQL Databases

---

# 2. Big Data

## Definition

Data too large or complex for traditional systems.

### Examples

- Facebook Data
- YouTube Data
- Netflix Data

---

# 3. Five V's of Big Data

## Volume

Amount of data.

## Velocity

Speed of generation.

## Variety

Different formats.

## Veracity

Data quality.

## Value

Business usefulness.

---

# Interview Questions

### Q1. What is Big Data?

Data too large or complex for traditional systems.

### Q2. What are 5 V's?

Volume, Velocity, Variety, Veracity, Value.

### Q3. Name Big Data tools.

Hadoop, Spark, Kafka.

### Q4. Is every TB dataset Big Data?

No.

### Q5. Why is Big Data important?

Provides business insights from massive datasets.
