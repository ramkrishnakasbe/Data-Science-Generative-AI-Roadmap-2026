# Network Analysis

## Overview

Network Analysis (also called **Graph Analytics**) is the study of relationships and interactions between entities using **graphs**. It helps uncover hidden patterns, influential nodes, communities, and the overall structure of connected data.

In Machine Learning and Data Science, Network Analysis is widely used in **social networks, recommendation systems, fraud detection, cybersecurity, transportation, biological networks, and knowledge graphs**.
